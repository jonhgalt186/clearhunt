Политика конфиденциальности

ClearHunt (раньше FilterJobHH). Дата: 20.10.2026

1. Общие положения

ClearHunt — браузерное расширение для локальной фильтрации вакансий на сайтах HeadHunter: hh.ru, hh.kz, hh.uz, rabota.by, headhunter.kg, headhunter.ge.

Расширение не собирает, не передаёт и не продаёт персональные данные пользователя.

2. Какие данные обрабатывает расширение

Только технические данные, нужные для фильтров, и только на вашем устройстве:

  • настройки фильтров;
  • чёрный список компаний;
  • список просмотренных вакансий с отметкой времени.

На страницах hh расширение читает содержимое карточек вакансий (название, работодатель, рейтинг и т.п.), чтобы скрыть или пометить их. Это происходит в браузере и не отправляется разработчику.

3. Где хранятся данные

Все пользовательские настройки и списки хранятся локально через storage браузера. Они не уходят на сервер разработчика и не передаются третьим лицам.

4. Что не собирается

  • ФИО, email, телефоны, пароли;
  • платёжные данные;
  • аналитика, рекламные трекеры, телеметрия;
  • история посещений сайтов вне работы фильтров на поддерживаемых страницах HeadHunter.

5. Внешние запросы

Расширение может загрузить JSON-файл с CSS-селекторами с GitHub (raw.githubusercontent.com), чтобы фильтр не ломался при смене вёрстки hh. Это данные конфигурации, не удалённый исполняемый код. Списки пользователя и настройки в этом запросе не передаются.

Ссылки на сайт расширения и страницу доната открываются только если пользователь сам на них нажимает.

6. Контакты

Вопросы по конфиденциальности: через карточку ClearHunt в магазине расширений (Chrome Web Store / Firefox Add-ons) или сайт jonhgalt186.github.io/clearhunt.
